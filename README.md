# Aera Selfcare — design sketch

Static design sketch of the new Aera Selfcare store (K-Beauty & J-Beauty, Panamá), for client review.

- Storefront: shelf-style catalog → bag → quotation (cotización) sent to the owner's WhatsApp. No online payment.
- Owner panel: `panel/` — quotes, inventory, clients, statistics (demo data, stored in the browser only).

Catalog data comes from the store's current public Treinta catalog. Not the final product.
